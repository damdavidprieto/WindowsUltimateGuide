# 🪟 Ventanas, Escritorios y Barra de Tareas

Organiza tu espacio de trabajo sin tocar el ratón.

## 📐 Snap (Ajustar ventanas)
| Atajo | Acción |
| :--- | :--- |
| `Win` + `Z` | Abrir los diseños de Snap. Después pulsa el número del diseño y de la zona. |
| `Win` + `←` / `→` | Ajustar la ventana a la mitad izquierda o derecha. |
| `Win` + `Alt` + `↑` / `↓` | Ajustar la ventana a la mitad superior o inferior. |
| `Win` + `↑` | Maximizar la ventana. |
| `Win` + `↓` | Restaurar o minimizar la ventana. |
| `Win` + `Shift` + `↓` | Restaurar una ventana ajustada o maximizada. |
| `Win` + `Shift` + `↑` | Estirar la ventana de arriba a abajo de la pantalla (mantiene el ancho). |
| `Win` + `Shift` + `Enter` | Pantalla completa en apps de la Store compatibles. |

> [!TIP]
> Después de ajustar una ventana a un lado, Windows te ofrece las demás ventanas para llenar el hueco. Elige una con las flechas y pulsa `Enter`.

## 🔀 Cambiar entre Ventanas
| Atajo | Acción |
| :--- | :--- |
| `Alt` + `Tab` | Cambiar entre ventanas abiertas. Con `Shift` vas en sentido contrario. |
| `Ctrl` + `Alt` + `Tab` | Mostrar las ventanas abiertas y dejar el selector abierto. Navega con flechas. |
| `Alt` + `Esc` | Pasar a la siguiente ventana en el orden en que se abrieron. |
| `Win` + `,` | Ver el escritorio temporalmente mientras mantienes `Win` pulsado. |
| `Win` + `D` | Mostrar u ocultar el escritorio. |
| `Win` + `M` | Minimizar todas las ventanas. |
| `Win` + `Shift` + `M` | Restaurar las ventanas minimizadas. |
| `Win` + `Inicio` | Minimizar todo excepto la ventana activa. |
| `Alt` + `F4` | Cerrar la ventana. En el escritorio, abre el diálogo de apagado. |
| `Alt` + `Espacio` | Menú de la ventana (mover, cambiar tamaño, cerrar). |
| `Ctrl` + `F4` | Cerrar el documento o la pestaña activa (en apps que lo admiten). |

## 🖥️ Escritorios Virtuales
| Atajo | Acción |
| :--- | :--- |
| `Win` + `Tab` | Abrir la Vista de tareas (ventanas y escritorios). |
| `Win` + `Ctrl` + `D` | Crear un nuevo escritorio virtual. |
| `Win` + `Ctrl` + `←` / `→` | Cambiar al escritorio de la izquierda o la derecha. |
| `Win` + `Ctrl` + `F4` | Cerrar el escritorio actual (sus ventanas pasan al escritorio de al lado). |

## 🖥️🖥️ Varios Monitores
| Atajo | Acción |
| :--- | :--- |
| `Win` + `Shift` + `←` / `→` | Mover la ventana activa al monitor de la izquierda o la derecha. |
| `Win` + `P` | Cambiar el modo de proyección (Duplicar, Extender…). |

## 📌 Barra de Tareas
| Atajo | Acción |
| :--- | :--- |
| `Win` + `1`…`9` | Abrir la app anclada en esa posición o cambiar a ella. |
| `Win` + `Shift` + `1`…`9` | Abrir otra ventana de esa app. |
| `Win` + `Ctrl` + `1`…`9` | Ir a la última ventana activa de esa app. |
| `Win` + `Alt` + `1`…`9` | Abrir la lista de accesos directos (archivos recientes, etc.) de esa app. |
| `Win` + `Ctrl` + `Shift` + `1`…`9` | Abrir esa app **como administrador**. |
| `Win` + `T` | Recorrer los iconos de la barra de tareas. Con `Shift` vas hacia atrás. |
| `Win` + `B` | Poner el foco en la bandeja del sistema (iconos junto al reloj). |
| `Win` + `Alt` + `Enter` | Abrir la configuración de la barra de tareas (con un icono seleccionado). |
| `Alt` + `Shift` + flecha | Mover el icono seleccionado en esa dirección. |
| `Shift` + clic en un icono | Abrir otra ventana de esa app. |
| `Ctrl` + `Shift` + clic en un icono | Abrir la app como administrador. |
| `Ctrl` + clic en un icono agrupado | Recorrer las ventanas de esa app. |
| `Shift` + clic derecho en un icono | Mostrar el menú de la ventana. |
