# 🪟 Ventanas, Escritorios y Barra de Tareas

Organiza las ventanas abiertas, crea escritorios virtuales y abre tus apps favoritas sin tocar el ratón.

## 🔀 Cambiar entre Ventanas
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Alt` + `Tab` | Cambia a otra ventana abierta. | Mantén `Alt` y pulsa `Tab` varias veces para elegir la ventana. El atajo más usado de Windows. | Básico |
| `Alt` + `Shift` + `Tab` | Cambia de ventana en sentido contrario. | Si te pasaste de la ventana que querías con `Alt` + `Tab`. | Intermedio |
| `Ctrl` + `Alt` + `Tab` | Muestra las ventanas y deja el selector abierto. | Para elegir ventana con calma, usando las flechas y `Enter`. | Intermedio |
| `Alt` + `Esc` | Pasa a la siguiente ventana en el orden en que se abrieron. | Para ir saltando entre ventanas sin ver el selector. | Avanzado |
| `Alt` + `F4` | Cierra la ventana activa. | Para cerrar un programa rápido. En el escritorio abre el menú de apagado. | Básico |
| `Ctrl` + `W` o `Ctrl` + `F4` | Cierra la pestaña o el documento activo. | En navegadores, Explorador, editores… para cerrar solo la pestaña, no el programa. | Básico |
| `Alt` + `Espacio` | Abre el menú de la ventana. | Para mover o cambiar el tamaño de una ventana con el teclado. | Avanzado |

## 🖥️ Escritorio
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `D` | Muestra u oculta el escritorio. | Para llegar a un archivo del escritorio. Púlsalo otra vez y vuelven tus ventanas. | Básico |
| `Win` + `M` | Minimiza todas las ventanas. | Para "despejar" la pantalla de golpe. | Intermedio |
| `Win` + `Shift` + `M` | Restaura las ventanas minimizadas. | Para recuperar todo lo que minimizaste con `Win` + `M`. | Intermedio |
| `Win` + `,` | Muestra el escritorio mientras mantienes pulsado `Win`. | Para echar un vistazo rápido al escritorio. Al soltar, todo vuelve. | Avanzado |
| `Win` + `Inicio` | Minimiza todo excepto la ventana activa. | Para concentrarte en una sola ventana. | Avanzado |

## 📐 Snap: Colocar Ventanas
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `←` / `→` | Coloca la ventana en la mitad izquierda o derecha. | Para tener dos ventanas lado a lado (por ejemplo, un documento y el navegador). | Básico |
| `Win` + `↑` | Maximiza la ventana. | Para que una ventana ocupe toda la pantalla. | Básico |
| `Win` + `↓` | Restaura o minimiza la ventana. | Para hacer pequeña una ventana maximizada, o minimizarla. | Básico |
| `Win` + `Z` | Abre los diseños de Snap. | Para colocar 3 o 4 ventanas en cuadrícula. Pulsa el número del diseño y de la zona. | Intermedio |
| `Win` + `Alt` + `↑` / `↓` | Coloca la ventana en la mitad superior o inferior. | En monitores verticales o muy grandes. | Avanzado |
| `Win` + `Shift` + `↓` | Restaura una ventana colocada o maximizada. | Para devolver una ventana a su tamaño normal. | Avanzado |
| `Win` + `Shift` + `↑` | Estira la ventana de arriba abajo. | Para tener una ventana alta sin cambiar su ancho. | Avanzado |
| `Win` + `Shift` + `Enter` | Pone en pantalla completa las apps de la Store compatibles. | Para ver una app sin bordes ni barra de tareas. | Avanzado |

> [!TIP]
> Al colocar una ventana a un lado, Windows te ofrece el resto de ventanas para llenar el otro lado. Elige una con las flechas y pulsa `Enter`.

## 🗂️ Escritorios Virtuales
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `Tab` | Abre la Vista de tareas. | Para ver todas tus ventanas y escritorios en grande. | Básico |
| `Win` + `Ctrl` + `D` | Crea un escritorio virtual nuevo. | Para separar trabajo y ocio, o proyectos distintos, cada uno en su escritorio. | Intermedio |
| `Win` + `Ctrl` + `←` / `→` | Cambia al escritorio de la izquierda o la derecha. | Para pasar de un escritorio a otro al instante. | Intermedio |
| `Win` + `Ctrl` + `F4` | Cierra el escritorio virtual actual. | Cuando ya no lo necesites. Sus ventanas pasan al escritorio de al lado. | Intermedio |

## 🖥️🖥️ Varios Monitores
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `Shift` + `←` / `→` | Mueve la ventana al monitor de la izquierda o la derecha. | Con dos pantallas, para pasar una ventana de una a otra sin arrastrarla. | Intermedio |
| `Win` + `P` | Cambia el modo de proyección. | Para elegir entre duplicar la pantalla o extenderla al segundo monitor. | Intermedio |

## 📌 Barra de Tareas
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `1`…`9` | Abre la app anclada en esa posición, o cambia a ella. | Si el navegador es el primer icono de la barra, `Win` + `1` lo abre siempre. | Intermedio |
| `Win` + `Shift` + `1`…`9` | Abre otra ventana de esa app. | Para abrir una segunda ventana del navegador o del Explorador. | Avanzado |
| `Win` + `Ctrl` + `1`…`9` | Va a la última ventana activa de esa app. | Cuando una app tiene varias ventanas abiertas. | Avanzado |
| `Win` + `Alt` + `1`…`9` | Abre la lista de accesos directos de esa app. | Para abrir un archivo reciente de Word o una carpeta anclada. | Avanzado |
| `Win` + `Ctrl` + `Shift` + `1`…`9` | Abre esa app como administrador. | Para programas que necesitan permisos especiales (Terminal, instaladores…). | Avanzado |
| `Win` + `T` | Recorre los iconos de la barra de tareas. | Para elegir una app de la barra con las flechas y `Enter`. | Avanzado |
| `Win` + `Shift` + `T` | Recorre la barra de tareas hacia atrás. | Igual que `Win` + `T`, en sentido contrario. | Avanzado |
| `Win` + `B` | Lleva el foco a los iconos junto al reloj. | Para abrir el antivirus, OneDrive u otros iconos ocultos sin ratón. | Avanzado |
| `Win` + `Alt` + `Enter` | Abre la configuración de la barra de tareas (con un icono seleccionado). | Para personalizar la barra de tareas. | Avanzado |
| `Alt` + `Shift` + flecha | Mueve el icono seleccionado. | Para reordenar los iconos de la barra con el teclado. | Avanzado |
| `Shift` + clic en un icono | Abre otra ventana de esa app. | Igual que `Win` + `Shift` + número, pero con el ratón. | Intermedio |
| `Ctrl` + `Shift` + clic en un icono | Abre la app como administrador. | Para abrir rápido una consola con permisos de administrador. | Avanzado |
| `Ctrl` + clic en un icono agrupado | Recorre las ventanas de esa app. | Para saltar entre varios documentos de la misma app. | Avanzado |
| `Shift` + clic derecho en un icono | Muestra el menú de la ventana. | Para restaurar, mover o cerrar una ventana desde la barra. | Avanzado |
