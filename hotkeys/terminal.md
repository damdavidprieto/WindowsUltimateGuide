# 🐚 Terminal, PowerShell y CMD

## 🖥️ Windows Terminal
Es la terminal predeterminada de Windows 11. Ábrela con `Win` + `X` y eligiendo **Terminal**, o escribe `wt` en `Win` + `R`.

### Pestañas y Ventanas
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `Shift` + `T` | Nueva pestaña con el perfil predeterminado. |
| `Ctrl` + `Shift` + `1`…`9` | Nueva pestaña con el perfil de esa posición (PowerShell, CMD, Ubuntu…). |
| `Ctrl` + `Shift` + `Espacio` | Menú para abrir una pestaña con cualquier perfil. |
| `Ctrl` + `Shift` + `D` | Duplicar la pestaña. |
| `Ctrl` + `Shift` + `N` | Nueva ventana. |
| `Ctrl` + `Shift` + `W` | Cerrar el panel o la pestaña. |
| `Ctrl` + `Tab` / `Ctrl` + `Shift` + `Tab` | Ir a la pestaña siguiente o la anterior. |
| `Ctrl` + `Alt` + `1`…`9` | Ir a la pestaña con ese número. |

### Paneles (dividir la pantalla)
| Atajo | Acción |
| :--- | :--- |
| `Alt` + `Shift` + `D` | Dividir duplicando el perfil actual (elige la dirección sola). |
| `Alt` + `Shift` + `+` | Dividir en vertical (panel nuevo a la derecha). |
| `Alt` + `Shift` + `-` | Dividir en horizontal (panel nuevo abajo). |
| `Alt` + flechas | Pasar el foco a otro panel. |
| `Alt` + `Shift` + flechas | Cambiar el tamaño del panel. |

### Uso General
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `Shift` + `P` | **Paleta de comandos**: busca cualquier acción. |
| `Ctrl` + `Shift` + `F` | Buscar en el texto de la terminal. |
| `Ctrl` + `,` | Abrir la configuración. |
| `Ctrl` + `C` | Copiar si hay texto seleccionado; si no, interrumpir el comando. |
| `Ctrl` + `V` | Pegar. |
| `Ctrl` + `Shift` + `A` | Seleccionar todo. |
| `Ctrl` + `Shift` + `M` | Modo marca: seleccionar texto con el teclado. |
| `Ctrl` + `=` / `Ctrl` + `-` / `Ctrl` + `0` | Ampliar, reducir o restablecer el tamaño de letra. |
| `Ctrl` + `Shift` + `↑` / `↓` | Desplazarse una línea. |
| `Ctrl` + `Shift` + `RePág` / `AvPág` | Desplazarse una página. |
| `Ctrl` + `Shift` + `Inicio` / `Fin` | Ir al principio o al final del historial. |
| `F11` o `Alt` + `Enter` | Pantalla completa. |
| `Win` + `` ` `` | **Modo Quake**: terminal desplegable desde arriba, disponible en cualquier momento. |

## ⚡ PowerShell (PSReadLine)
PowerShell 7 y Windows PowerShell 5.1 usan PSReadLine para editar la línea de comandos.

| Atajo | Acción |
| :--- | :--- |
| `Tab` / `Shift` + `Tab` | Autocompletar (siguiente o anterior opción). |
| `Ctrl` + `Espacio` | Mostrar **todas** las opciones de autocompletado en un menú. |
| `→` (al final de la línea) | Aceptar la predicción del historial (texto en gris). |
| `Ctrl` + `→` | Aceptar solo la siguiente palabra de la predicción. |
| `F2` | Cambiar las predicciones entre una línea y una lista. |
| `Ctrl` + `R` | Buscar hacia atrás en el historial (escribe parte del comando). |
| `F8` | Buscar en el historial comandos que empiecen por lo que has escrito. |
| `↑` / `↓` | Recorrer el historial. |
| `Alt` + `.` | Insertar el último argumento del comando anterior. |
| `Shift` + `Enter` | Añadir una línea nueva sin ejecutar. |
| `Esc` | Borrar la línea actual. |
| `Ctrl` + `L` | Limpiar la pantalla. |
| `Ctrl` + `Retroceso` / `Ctrl` + `Supr` | Borrar la palabra anterior o la siguiente. |
| `Ctrl` + `Z` / `Ctrl` + `Y` | Deshacer o rehacer en la línea. |
| `Ctrl` + `C` | Cancelar el comando en ejecución. |

## 📟 CMD (Símbolo del sistema)
| Atajo | Acción |
| :--- | :--- |
| `Tab` | Autocompletar nombres de archivos y carpetas. |
| `↑` / `↓` | Recorrer el historial. |
| `F7` | Ver el historial en una lista. |
| `F8` | Buscar en el historial comandos que empiecen por lo que has escrito. |
| `F9` | Ejecutar un comando del historial por su número. |
| `F3` | Repetir el último comando. |
| `F1` | Repetir el último comando carácter a carácter. |
| `Esc` | Borrar la línea actual. |
| `Ctrl` + `C` | Interrumpir el comando. |
