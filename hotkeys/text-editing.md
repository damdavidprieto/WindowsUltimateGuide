# ✍️ Texto y Cuadros de Diálogo

Estos atajos funcionan en **casi cualquier programa**: el Bloc de notas, Word, el correo, el navegador, los formularios web… Si solo aprendes una página, que sea esta.

## 📋 Copiar, Pegar y Deshacer
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Ctrl` + `C` | Copia lo seleccionado. | Para duplicar un texto, imagen o archivo en otro sitio. | Básico |
| `Ctrl` + `X` | Corta lo seleccionado. | Para mover un texto a otro sitio (desaparece de aquí al pegarlo). | Básico |
| `Ctrl` + `V` | Pega lo copiado o cortado. | En el lugar donde quieras ponerlo. | Básico |
| `Win` + `V` | Pega desde el historial del portapapeles. | Para pegar algo que copiaste antes que lo último. Puedes anclar textos que uses mucho. | Básico |
| `Ctrl` + `Shift` + `V` | Pega sin formato (solo el texto). | Al pegar algo de una web en un documento, para que no traiga colores ni tipos de letra raros. Funciona en Edge, Chrome, Word y muchas apps. | Intermedio |
| `Ctrl` + `Z` | Deshace lo último. | Siempre que te equivoques. Puedes pulsarlo varias veces. | Básico |
| `Ctrl` + `Y` | Rehace lo deshecho. | Si deshiciste de más. | Básico |
| `Ctrl` + `A` | Selecciona todo. | Para copiar o borrar todo el texto de un documento o campo. | Básico |

## 💾 Archivo
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Ctrl` + `S` | Guarda. | Cada pocos minutos, para no perder tu trabajo. | Básico |
| `Ctrl` + `N` | Crea un documento o ventana nueva. | Para empezar un documento en blanco. | Básico |
| `Ctrl` + `O` | Abre un archivo. | Para abrir un documento desde el programa. | Básico |
| `Ctrl` + `P` | Imprime. | También sirve para guardar como PDF (elige "Microsoft Print to PDF"). | Básico |
| `Ctrl` + `F` | Busca. | Para encontrar una palabra en un texto largo o una web. | Básico |
| `Ctrl` + `H` | Busca y reemplaza. | Para cambiar una palabra por otra en todo el documento. | Intermedio |
| `Ctrl` + `W` | Cierra el documento o la pestaña. | Para cerrar sin salir del programa. | Básico |
| `F1` | Abre la ayuda. | Cuando no sabes cómo hacer algo en un programa. | Intermedio |

## 🏃 Moverse por el Texto
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Ctrl` + `←` / `→` | Salta palabra a palabra. | Para llegar rápido a una palabra sin pulsar la flecha muchas veces. | Básico |
| `Inicio` / `Fin` | Va al principio o al final de la línea. | Para añadir algo al final de una línea. | Básico |
| `Ctrl` + `Inicio` / `Fin` | Va al principio o al final del documento. | En documentos largos, para ir al principio o al final de golpe. | Básico |
| `RePág` / `AvPág` | Sube o baja una pantalla. | Para leer un documento largo. | Básico |
| `Ctrl` + `↑` / `↓` | Salta de párrafo en párrafo. | En Word y editores compatibles. | Intermedio |

## 🖍️ Seleccionar Texto
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Shift` + `←` / `→` | Selecciona letra a letra. | Para seleccionar con precisión. | Básico |
| `Shift` + `↑` / `↓` | Selecciona línea a línea. | Para seleccionar varias líneas. | Básico |
| `Ctrl` + `Shift` + `←` / `→` | Selecciona palabra a palabra. | La forma más rápida de seleccionar una frase. | Intermedio |
| `Shift` + `Inicio` / `Fin` | Selecciona hasta el principio o el final de la línea. | Para seleccionar una línea entera de un golpe. | Intermedio |
| `Ctrl` + `Shift` + `Inicio` / `Fin` | Selecciona hasta el principio o el final del documento. | Para seleccionar todo lo que hay por encima o por debajo. | Intermedio |
| Doble clic | Selecciona una palabra. | Para seleccionar una palabra rápidamente. | Básico |
| Triple clic | Selecciona el párrafo o la línea. | Para seleccionar un párrafo entero. | Básico |
| `Shift` + clic | Selecciona desde el cursor hasta donde haces clic. | Para seleccionar trozos largos de texto sin arrastrar. | Intermedio |

## 🧹 Borrar
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Retroceso` | Borra la letra anterior. | El borrado normal. | Básico |
| `Supr` | Borra la letra siguiente. | Para borrar lo que hay a la derecha del cursor. | Básico |
| `Ctrl` + `Retroceso` | Borra la palabra anterior. | Para borrar palabras enteras de una vez. | Intermedio |
| `Ctrl` + `Supr` | Borra la palabra siguiente. | Igual, hacia la derecha. | Intermedio |

## 🎨 Formato (Word, Outlook, correo…)
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Ctrl` + `N` (Office en español) | Negrita. | En Word u Outlook en español. En casi todas las demás apps es `Ctrl` + `B`. | Básico |
| `Ctrl` + `B` | Negrita (apps en inglés, Google Docs, correo web). | Para resaltar palabras importantes. | Básico |
| `Ctrl` + `K` (Office en español) | Cursiva. | En Word u Outlook en español. En el resto, `Ctrl` + `I`. | Básico |
| `Ctrl` + `I` | Cursiva (apps en inglés, Google Docs, correo web). | Para títulos de libros o palabras extranjeras. | Básico |
| `Ctrl` + `S` (Office en español) | Subrayado. **Ojo:** en Office en español no guarda. | Para guardar en Office en español usa `Ctrl` + `G`. | Básico |
| `Ctrl` + `U` | Subrayado (apps en inglés, Google Docs, correo web). | Para subrayar texto. | Básico |
| `Ctrl` + `G` (Office en español) | Guarda. | En Word, Excel y PowerPoint en español. | Básico |

## 🪟 Cuadros de Diálogo y Formularios
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Tab` | Pasa al siguiente campo o botón. | Al rellenar un formulario: escribe tu nombre, pulsa `Tab` y escribe el apellido. | Básico |
| `Shift` + `Tab` | Vuelve al campo anterior. | Para corregir el campo de antes. | Básico |
| `Enter` | Acepta o pulsa el botón seleccionado. | Para confirmar un cuadro de diálogo. | Básico |
| `Esc` | Cancela o cierra. | Para cerrar un cuadro de diálogo o un menú sin hacer nada. | Básico |
| `Espacio` | Marca o desmarca una casilla; pulsa el botón seleccionado. | Para activar opciones con el teclado. | Básico |
| `Ctrl` + `Tab` | Cambia de pestaña dentro del cuadro de diálogo. | En ventanas de opciones con varias pestañas. | Intermedio |
| `Alt` + letra subrayada | Activa esa opción. | Pulsa `Alt` para ver qué letra tiene cada opción. | Intermedio |
| `F4` o `Alt` + `↓` | Abre una lista desplegable. | Para elegir de una lista sin ratón. | Intermedio |
| `Retroceso` (en Abrir/Guardar) | Sube a la carpeta superior. | Al buscar un archivo en el cuadro "Abrir". | Avanzado |
| `F10` o `Alt` | Activa la barra de menús. | Para navegar por los menús (Archivo, Edición…) con flechas. | Intermedio |
