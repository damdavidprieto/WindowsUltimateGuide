# ✍️ Texto y Cuadros de Diálogo

Atajos universales: funcionan en casi cualquier app, desde el Bloc de notas hasta Word o el navegador.

## 📋 Básicos
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `C` / `Ctrl` + `X` / `Ctrl` + `V` | Copiar, cortar y pegar. |
| `Win` + `V` | Pegar desde el **historial del portapapeles**. Puedes anclar elementos. |
| `Ctrl` + `Shift` + `V` | Pegar **sin formato** (en Edge, Chrome, Word y otras apps). |
| `Ctrl` + `Z` / `Ctrl` + `Y` | Deshacer y rehacer. |
| `Ctrl` + `A` | Seleccionar todo. |
| `Ctrl` + `F` | Buscar. |
| `Ctrl` + `H` | Buscar y reemplazar (en editores). |
| `Ctrl` + `S` | Guardar. |
| `Ctrl` + `P` | Imprimir. |
| `Ctrl` + `N` / `Ctrl` + `O` | Nuevo / Abrir. |

> [!TIP]
> Con **PowerToys** (Pegado avanzado), `Win` + `Ctrl` + `Alt` + `V` pega sin formato en **cualquier** app, y `Win` + `Shift` + `V` abre el menú para pegar como Markdown, JSON o texto extraído de una imagen.

## 🏃 Moverse por el Texto
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `←` / `→` | Saltar palabra a palabra. |
| `Ctrl` + `↑` / `↓` | Saltar de párrafo en párrafo (en apps compatibles). |
| `Inicio` / `Fin` | Ir al principio o al final de la línea. |
| `Ctrl` + `Inicio` / `Ctrl` + `Fin` | Ir al principio o al final del documento. |
| `RePág` / `AvPág` | Subir o bajar una pantalla. |

## 🖍️ Seleccionar
| Atajo | Acción |
| :--- | :--- |
| `Shift` + flechas | Seleccionar carácter a carácter o línea a línea. |
| `Ctrl` + `Shift` + `←` / `→` | Seleccionar palabra a palabra. |
| `Shift` + `Inicio` / `Fin` | Seleccionar hasta el principio o el final de la línea. |
| `Ctrl` + `Shift` + `Inicio` / `Fin` | Seleccionar hasta el principio o el final del documento. |
| Doble clic / Triple clic | Seleccionar la palabra / el párrafo o la línea. |

## 🧹 Borrar
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `Retroceso` | Borrar la palabra anterior. |
| `Ctrl` + `Supr` | Borrar la palabra siguiente. |

## 🎨 Formato (Word, Outlook, WordPad, correo…)
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `B` / `Ctrl` + `N` | Negrita (`Ctrl` + `N` en Office en español). |
| `Ctrl` + `I` / `Ctrl` + `K` | Cursiva (`Ctrl` + `K` en Office en español). |
| `Ctrl` + `U` / `Ctrl` + `S` | Subrayado (`Ctrl` + `S` en Office en español). |
| `Ctrl` + `K` / `Ctrl` + `Alt` + `K` | Insertar hipervínculo (`Ctrl` + `Alt` + `K` en Office en español). |

> [!NOTE]
> **Office en español** cambia algunos atajos de formato: **N**egrita, **K**ursiva, **S**ubrayado. Por eso `Ctrl` + `S` subraya en lugar de guardar; para guardar usa `Ctrl` + `G` o `Shift` + `F12`. La mayoría de las demás apps usan los atajos en inglés.

## 🪟 Cuadros de Diálogo y Formularios
| Atajo | Acción |
| :--- | :--- |
| `Tab` / `Shift` + `Tab` | Ir al control siguiente o al anterior. |
| `Ctrl` + `Tab` / `Ctrl` + `Shift` + `Tab` | Cambiar de pestaña dentro del cuadro de diálogo. |
| `Alt` + letra subrayada | Activar esa opción. Pulsa `Alt` para ver las letras. |
| `Espacio` | Marcar o desmarcar una casilla; pulsar el botón seleccionado. |
| `Enter` / `Esc` | Aceptar / Cancelar. |
| `F4` o `Alt` + `↓` | Abrir una lista desplegable. |
| `Retroceso` (en Abrir/Guardar) | Subir a la carpeta superior. |
| `F10` | Activar la barra de menús de la app. |
