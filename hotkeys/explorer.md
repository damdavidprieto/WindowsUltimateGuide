# 📂 Explorador de Archivos

Muévete por tus carpetas con la agilidad de un profesional. Para abrirlo: `Win` + `E`.

## 🗂️ Pestañas y Ventanas
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `T` | Nueva pestaña. |
| `Ctrl` + `W` | Cerrar la pestaña. Si solo hay una, cierra la ventana. |
| `Ctrl` + `Tab` / `Ctrl` + `Shift` + `Tab` | Ir a la pestaña siguiente o la anterior. |
| `Ctrl` + `1`…`9` | Ir a la pestaña con ese número. |
| `Ctrl` + `N` | Nueva ventana. |
| `F11` | Pantalla completa. |

## 🧭 Navegación
| Atajo | Acción |
| :--- | :--- |
| `Alt` + `D` o `Ctrl` + `L` | Seleccionar la barra de direcciones para escribir una ruta. |
| `F4` | Abrir la lista de rutas recientes de la barra de direcciones. |
| `Ctrl` + `E`, `Ctrl` + `F` o `F3` | Ir al cuadro de búsqueda. |
| `Alt` + `↑` | Subir un nivel (carpeta padre). |
| `Alt` + `←` o `Retroceso` | Volver a la carpeta anterior. |
| `Alt` + `→` | Avanzar a la carpeta siguiente. |
| `F6` | Recorrer las zonas de la ventana (navegación, archivos, dirección). |
| `Inicio` / `Fin` | Ir al primer o al último elemento. |
| `←` / `→` en el panel de navegación | Contraer o expandir la carpeta seleccionada. |
| `Ctrl` + `Shift` + `E` | Expandir todas las carpetas del panel de navegación. |

> [!TIP]
> En la barra de direcciones puedes escribir `cmd`, `wt` o `powershell` y pulsar `Enter` para abrir una consola **en esa carpeta**.

## 👁️ Vistas y Paneles
| Atajo | Acción |
| :--- | :--- |
| `Alt` + `P` | Mostrar u ocultar el panel de vista previa. |
| `Alt` + `Shift` + `P` | Mostrar u ocultar el panel de detalles. |
| `Ctrl` + `Shift` + `1` | Iconos muy grandes. |
| `Ctrl` + `Shift` + `2` | Iconos grandes. |
| `Ctrl` + `Shift` + `3` | Iconos medianos. |
| `Ctrl` + `Shift` + `4` | Iconos pequeños. |
| `Ctrl` + `Shift` + `5` | Lista. |
| `Ctrl` + `Shift` + `6` | Detalles. |
| `Ctrl` + `Shift` + `7` | Mosaicos. |
| `Ctrl` + `Shift` + `8` | Contenido. |
| `Ctrl` + rueda del ratón | Cambiar el tamaño de los iconos poco a poco. |
| `F5` | Actualizar la vista. |

## 📄 Archivos y Carpetas
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `Shift` + `N` | Nueva carpeta. |
| `F2` | Cambiar el nombre. Pulsa `Tab` para pasar al siguiente archivo y seguir renombrando. |
| `Ctrl` + `Shift` + `C` | **Copiar la ruta** del elemento (con comillas). |
| `Alt` + `Enter` | Propiedades del elemento. |
| `Ctrl` + `D` o `Supr` | Enviar a la Papelera. |
| `Shift` + `Supr` | Eliminar de forma permanente (sin pasar por la Papelera). |
| `Ctrl` + `Z` / `Ctrl` + `Y` | Deshacer o rehacer (mover, renombrar, eliminar…). |
| `Shift` + `F10` o tecla Menú | Abrir el menú contextual. |
| `Shift` + clic derecho | Abrir el menú contextual clásico ("Mostrar más opciones"). |
| `Enter` | Abrir el elemento seleccionado. |

## ✅ Selección y Arrastre
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `A` | Seleccionar todo. |
| `Shift` + flechas | Seleccionar varios elementos seguidos. |
| `Ctrl` + flechas y luego `Espacio` | Seleccionar elementos sueltos (no consecutivos). |
| `Ctrl` + arrastrar | **Copiar** el archivo al destino. |
| `Shift` + arrastrar | **Mover** el archivo al destino. |
| `Alt` + arrastrar | Crear un **acceso directo** en el destino. |
