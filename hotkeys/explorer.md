# 📂 Explorador de Archivos

El Explorador es donde ves y organizas tus carpetas y archivos. Ábrelo con `Win` + `E`.

## 🗂️ Pestañas y Ventanas
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `E` | Abre el Explorador de archivos. | Siempre que necesites buscar, abrir o mover un archivo. | Básico |
| `Ctrl` + `T` | Abre una pestaña nueva. | Para tener varias carpetas abiertas en la misma ventana, como en un navegador. | Intermedio |
| `Ctrl` + `W` | Cierra la pestaña (o la ventana si solo hay una). | Para cerrar una carpeta que ya no necesitas. | Básico |
| `Ctrl` + `Tab` | Va a la pestaña siguiente. | Para cambiar entre carpetas abiertas en pestañas. | Intermedio |
| `Ctrl` + `Shift` + `Tab` | Va a la pestaña anterior. | Igual, en sentido contrario. | Intermedio |
| `Ctrl` + `1`…`9` | Va a la pestaña con ese número. | Para saltar directamente a la tercera pestaña con `Ctrl` + `3`. | Avanzado |
| `Ctrl` + `N` | Abre una ventana nueva del Explorador. | Para tener dos ventanas y arrastrar archivos de una a otra. | Intermedio |
| `F11` | Pone la ventana en pantalla completa. | Para ver muchos archivos a la vez. | Avanzado |

## 🧭 Moverse por las Carpetas
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Alt` + `↑` | Sube a la carpeta superior. | Para salir de una carpeta y volver a la que la contiene. | Básico |
| `Alt` + `←` o `Retroceso` | Vuelve a la carpeta anterior. | Como el botón "Atrás" del navegador. | Básico |
| `Alt` + `→` | Avanza a la carpeta siguiente. | Para volver adonde estabas después de ir atrás. | Intermedio |
| `Alt` + `D` o `Ctrl` + `L` | Selecciona la barra de direcciones. | Para escribir o copiar la ruta de la carpeta (por ejemplo, `C:\Users`). | Intermedio |
| `F4` | Abre la lista de rutas de la barra de direcciones. | Para volver a una carpeta que visitaste hace poco. | Avanzado |
| `Ctrl` + `E` o `Ctrl` + `F` | Va al cuadro de búsqueda. | Para buscar un archivo dentro de la carpeta actual. | Básico |
| `F3` | Va al cuadro de búsqueda. | Igual que `Ctrl` + `F`. | Intermedio |
| `F6` | Recorre las zonas de la ventana. | Para pasar del panel izquierdo a la lista de archivos sin ratón. | Avanzado |
| `Inicio` / `Fin` | Va al primer o al último elemento. | En carpetas con muchos archivos. | Intermedio |
| Escribir las primeras letras | Salta al primer archivo que empieza así. | Escribe "inf" para ir directamente a "Informe.docx". | Intermedio |
| `←` / `→` en el panel izquierdo | Contrae o expande la carpeta. | Para navegar por el árbol de carpetas con el teclado. | Avanzado |
| `Ctrl` + `Shift` + `E` | Expande todas las carpetas del panel izquierdo. | Para ver toda la estructura de carpetas de golpe. | Avanzado |

> [!TIP]
> En la barra de direcciones (`Alt` + `D`) puedes escribir `cmd` o `wt` y pulsar `Enter` para abrir una consola **en esa carpeta**.

## 📄 Trabajar con Archivos
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Enter` | Abre el archivo o la carpeta seleccionada. | Igual que hacer doble clic. | Básico |
| `F2` | Cambia el nombre del archivo. | Para renombrar. Pulsa `Tab` al terminar para pasar al siguiente archivo. | Básico |
| `Ctrl` + `C` | Copia el archivo. | Para hacer una copia en otra carpeta (luego `Ctrl` + `V`). | Básico |
| `Ctrl` + `X` | Corta el archivo. | Para moverlo a otra carpeta (luego `Ctrl` + `V`). | Básico |
| `Ctrl` + `V` | Pega el archivo copiado o cortado. | En la carpeta de destino. | Básico |
| `Ctrl` + `Shift` + `N` | Crea una carpeta nueva. | Para organizar archivos. Escribe el nombre y pulsa `Enter`. | Básico |
| `Supr` o `Ctrl` + `D` | Envía a la Papelera. | Para borrar un archivo (podrás recuperarlo de la Papelera). | Básico |
| `Shift` + `Supr` | Borra para siempre, sin pasar por la Papelera. | Solo si estás seguro: no se puede recuperar fácilmente. | Intermedio |
| `Ctrl` + `Z` | Deshace la última acción. | Si borraste, moviste o renombraste algo sin querer. | Básico |
| `Ctrl` + `Y` | Rehace lo deshecho. | Si te arrepientes de haber deshecho. | Intermedio |
| `Alt` + `Enter` | Abre las Propiedades. | Para ver el tamaño, la fecha o la ubicación de un archivo. | Intermedio |
| `Ctrl` + `Shift` + `C` | Copia la ruta completa del archivo. | Para pegar la ubicación exacta en un correo, chat o programa. | Intermedio |
| `Shift` + `F10` | Abre el menú contextual. | Igual que hacer clic derecho. | Intermedio |
| `Shift` + clic derecho | Abre el menú contextual clásico completo. | Cuando necesitas una opción que está en "Mostrar más opciones". | Avanzado |

## ✅ Seleccionar Varios Archivos
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Ctrl` + `A` | Selecciona todo. | Para copiar o mover todos los archivos de una carpeta. | Básico |
| `Ctrl` + clic | Añade o quita un archivo de la selección. | Para elegir varios archivos sueltos. | Básico |
| `Shift` + clic | Selecciona desde el último archivo hasta donde haces clic. | Para seleccionar un grupo de archivos seguidos. | Básico |
| `Shift` + flechas | Amplía la selección con el teclado. | Para seleccionar archivos seguidos sin ratón. | Intermedio |
| `Ctrl` + flechas y luego `Espacio` | Selecciona archivos sueltos con el teclado. | Mueve el foco con `Ctrl` + flechas y marca cada archivo con `Espacio`. | Avanzado |
| `Ctrl` + arrastrar | Copia el archivo al soltarlo. | Para copiar (en vez de mover) arrastrando. | Intermedio |
| `Shift` + arrastrar | Mueve el archivo al soltarlo. | Para mover entre discos distintos (por defecto ahí se copia). | Intermedio |
| `Alt` + arrastrar | Crea un acceso directo al soltarlo. | Para poner un acceso directo a un programa o carpeta en el escritorio. | Avanzado |

## 👁️ Vistas y Paneles
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Alt` + `P` | Muestra u oculta el panel de vista previa. | Para ver el contenido de fotos, PDF o documentos sin abrirlos. | Intermedio |
| `Alt` + `Shift` + `P` | Muestra u oculta el panel de detalles. | Para ver el tamaño, la fecha o el autor del archivo seleccionado. | Avanzado |
| `Ctrl` + `Shift` + `1` | Vista de iconos muy grandes. | Para ver bien las miniaturas de fotos. | Avanzado |
| `Ctrl` + `Shift` + `2` | Vista de iconos grandes. | Para carpetas de imágenes. | Avanzado |
| `Ctrl` + `Shift` + `3` | Vista de iconos medianos. | Vista equilibrada. | Avanzado |
| `Ctrl` + `Shift` + `4` | Vista de iconos pequeños. | Para ver muchos archivos a la vez. | Avanzado |
| `Ctrl` + `Shift` + `5` | Vista de lista. | Para listas largas de nombres. | Avanzado |
| `Ctrl` + `Shift` + `6` | Vista de detalles. | Para ordenar por fecha, tamaño o tipo. La más útil para trabajar. | Intermedio |
| `Ctrl` + `Shift` + `7` | Vista de mosaicos. | Iconos con algo de información. | Avanzado |
| `Ctrl` + `Shift` + `8` | Vista de contenido. | Para ver más información de cada archivo. | Avanzado |
| `Ctrl` + rueda del ratón | Cambia el tamaño de los iconos poco a poco. | Para ajustar el tamaño a tu gusto. | Intermedio |
| `F5` | Actualiza la vista. | Si un archivo nuevo no aparece todavía. | Básico |
