# ♿ Accesibilidad

Atajos para ver, oír y usar el teclado con más comodidad. Todos se configuran en *Configuración > Accesibilidad* (`Win` + `U`).

## ⚙️ General
| Atajo | Acción |
| :--- | :--- |
| `Win` + `U` | Abrir la configuración de Accesibilidad. |
| `Win` + `Ctrl` + `L` | Activar o desactivar los **subtítulos en directo**. |
| `Win` + `H` | Escritura por voz (dictado). |
| `Win` + `Ctrl` + `O` | Teclado en pantalla. |
| `Win` + `Ctrl` + `C` | Activar o desactivar los filtros de color (hay que activar el atajo antes). |
| `Alt` izq. + `Shift` izq. + `ImprPant` | Activar o desactivar el tema de contraste. |

## 🔎 Lupa
| Atajo | Acción |
| :--- | :--- |
| `Win` + `+` | Abrir la Lupa o acercar. |
| `Win` + `-` | Alejar. |
| `Win` + `Esc` | Cerrar la Lupa. |
| `Ctrl` + `Alt` + `F` | Vista de pantalla completa. |
| `Ctrl` + `Alt` + `L` | Vista de lente. |
| `Ctrl` + `Alt` + `D` | Vista acoplada. |
| `Ctrl` + `Alt` + `M` | Cambiar entre vistas. |
| `Ctrl` + `Alt` + rueda del ratón | Acercar o alejar con la rueda. |

## 🗣️ Narrador
La tecla Narrador es `Bloq Mayús` o `Insert`.

| Atajo | Acción |
| :--- | :--- |
| `Win` + `Ctrl` + `Enter` | Activar o desactivar el Narrador. |
| `Ctrl` | Dejar de leer. |
| Narrador + `F1` | Ver la lista de todos los comandos del Narrador. |

## ⌨️ Teclas Especiales
| Atajo | Acción |
| :--- | :--- |
| `Shift` 5 veces | Teclas especiales (Sticky Keys): pulsar las combinaciones de una en una. |
| `Shift` der. 8 segundos | Teclas filtro: ignora pulsaciones breves o repetidas. |
| `Bloq Num` 5 segundos | Teclas de alternancia: pitido al pulsar Bloq Mayús, Bloq Num o Bloq Despl. |
| `Alt` izq. + `Shift` izq. + `Bloq Num` | Teclas del mouse: mover el puntero con el teclado numérico. |

> [!TIP]
> Si estas ventanas te saltan sin querer (por ejemplo, jugando), desactiva el atajo en *Accesibilidad > Teclado*.
