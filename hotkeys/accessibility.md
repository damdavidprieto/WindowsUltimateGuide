# ♿ Accesibilidad

Atajos para ver mejor, oír mejor y usar el teclado con más comodidad. Todo se configura en *Configuración > Accesibilidad* (`Win` + `U`).

## ⚙️ General
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `U` | Abre la configuración de Accesibilidad. | Para cambiar el tamaño del texto, el puntero, el contraste… | Básico |
| `Win` + `Ctrl` + `L` | Activa o desactiva los subtítulos en directo. | Para leer lo que se dice en un vídeo o una llamada. | Intermedio |
| `Win` + `H` | Activa la escritura por voz. | Para dictar en lugar de escribir. | Intermedio |
| `Win` + `Ctrl` + `O` | Abre el teclado en pantalla. | Si una tecla de tu teclado no funciona, o en tabletas. | Intermedio |
| `Win` + `Ctrl` + `C` | Activa o desactiva los filtros de color. | Para daltonismo o escala de grises. Activa antes el atajo en Configuración. | Avanzado |
| `Alt` izq. + `Shift` izq. + `ImprPant` | Activa o desactiva el contraste alto. | Si te cuesta leer la pantalla. | Avanzado |

## 🔎 Lupa
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `+` | Abre la Lupa o acerca. | Para ampliar algo que se ve muy pequeño. | Básico |
| `Win` + `-` | Aleja. | Para reducir el aumento. | Básico |
| `Win` + `Esc` | Cierra la Lupa. | Para volver a la vista normal. | Básico |
| `Ctrl` + `Alt` + `F` | Lupa a pantalla completa. | Para ampliar toda la pantalla. | Intermedio |
| `Ctrl` + `Alt` + `L` | Lupa en modo lente. | Para ampliar solo la zona alrededor del puntero. | Intermedio |
| `Ctrl` + `Alt` + `D` | Lupa acoplada arriba. | Para ver la zona ampliada en una franja fija. | Intermedio |
| `Ctrl` + `Alt` + `M` | Cambia entre los modos de la Lupa. | Para probar los distintos modos. | Intermedio |
| `Ctrl` + `Alt` + rueda del ratón | Acerca o aleja con la rueda. | Para ajustar el aumento con precisión. | Intermedio |

## 🗣️ Narrador (lector de pantalla)
La tecla *Narrador* es `Bloq Mayús` o `Insert`.

| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `Ctrl` + `Enter` | Activa o desactiva el Narrador. | Para que el PC lea en voz alta lo que hay en pantalla. | Intermedio |
| `Ctrl` | Deja de leer. | Para callar al Narrador en cualquier momento. | Intermedio |
| `Bloq Mayús` + `F1` | Muestra todos los comandos del Narrador. | Para aprender a usarlo. | Avanzado |

## ⌨️ Ayudas del Teclado
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Shift` 5 veces | Activa las teclas especiales. | Si te cuesta pulsar varias teclas a la vez: permite pulsarlas de una en una. | Intermedio |
| `Shift` derecha durante 8 segundos | Activa las teclas filtro. | Si pulsas teclas sin querer o se repiten: ignora las pulsaciones muy cortas. | Avanzado |
| `Bloq Num` durante 5 segundos | Activa las teclas de alternancia. | Para oír un pitido al pulsar `Bloq Mayús` o `Bloq Num`. | Avanzado |
| `Alt` izq. + `Shift` izq. + `Bloq Num` | Activa las teclas del mouse. | Para mover el puntero con el teclado numérico si el ratón falla. | Avanzado |

> [!TIP]
> Si estas ventanas te aparecen sin querer (por ejemplo, jugando), desactiva sus atajos en *Configuración > Accesibilidad > Teclado*.
