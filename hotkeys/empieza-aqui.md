# 🎓 Empieza Aquí: Cómo Usar los Atajos

Si nunca has usado atajos de teclado, esta página es para ti. En 5 minutos sabrás leer y usar cualquier atajo de esta guía.

## 🤔 ¿Qué es un atajo de teclado?
Un atajo es una **combinación de teclas que hace algo al instante**, sin usar el ratón. Por ejemplo, en lugar de ir a *Inicio > Explorador de archivos*, pulsas `Win` + `E` y se abre directamente.

Ahorran tiempo y, con práctica, te harán trabajar mucho más cómodo.

## 👆 Cómo se pulsa una combinación
Cuando veas `Ctrl` + `C`:

1. **Mantén pulsada** la primera tecla (`Ctrl`). No la sueltes.
2. **Pulsa una vez** la última tecla (`C`).
3. **Suelta** todas las teclas.

Si hay tres teclas, como `Win` + `Shift` + `S`, mantén pulsadas las dos primeras (`Win` y `Shift`) y pulsa la última (`S`). No hace falta pulsarlas exactamente a la vez.

> [!TIP]
> En esta web, pulsa el botón **⌨️** de cualquier atajo para ver **en un teclado dibujado** qué teclas tienes que pulsar.

## 🔗 Atajos en dos pasos
Algunos atajos (sobre todo en Visual Studio y VS Code) se escriben así: `Ctrl` + `K`, `Ctrl` + `C`. La coma significa **dos pasos**:

1. Pulsa `Ctrl` + `K` y suelta.
2. Pulsa `Ctrl` + `C` y suelta.

## 🗺️ Dónde están las teclas especiales

| Tecla | Dónde está | Para qué se usa |
| :--- | :--- | :--- |
| `Win` | Abajo a la izquierda, entre `Ctrl` y `Alt`. Tiene el logo de Windows (⊞). | Atajos del sistema: abrir apps, ventanas, capturas… |
| `Ctrl` | Las dos esquinas de abajo. | Atajos dentro de las apps: copiar, pegar, guardar… |
| `Alt` | A los lados de la barra espaciadora. A la derecha suele ser `AltGr`, que es otra tecla. | Menús, cambiar de ventana, mover líneas… |
| `Shift` (⇧) | Encima de `Ctrl`, con una flecha hacia arriba. Es la tecla de mayúsculas. | Seleccionar, invertir el sentido de otros atajos. |
| `Tab` | A la izquierda, encima de `Bloq Mayús`. Tiene dos flechas. | Pasar al siguiente campo o elemento. |
| `Esc` | Arriba a la izquierda. | Cancelar o cerrar. |
| `Enter` | A la derecha, la tecla grande de "Intro". | Aceptar o abrir. |
| `Retroceso` | Encima de `Enter`, con una flecha hacia la izquierda. | Borrar hacia atrás. |
| `Supr` | En el bloque de la derecha (en portátiles, arriba a la derecha). | Borrar hacia delante o eliminar archivos. |
| `F1`…`F12` | Fila superior del teclado. | Funciones rápidas: `F2` renombra, `F5` actualiza… |
| `ImprPant` | Arriba a la derecha. A veces pone *PrtScn* o *Impr Pant*. | Capturas de pantalla. |
| `Inicio` / `Fin` | Bloque de navegación (en portátiles, a veces con `Fn`). | Ir al principio o al final. |
| `←` `→` `↑` `↓` | Abajo a la derecha. | Moverse; combinadas con otras teclas hacen mucho más. |

## 💻 Si tienes un portátil: la tecla `Fn`
En muchos portátiles, las teclas `F1`…`F12` controlan el brillo o el volumen. Para usarlas como `F2`, `F5`, etc., **mantén pulsada `Fn`** a la vez. Algunos portátiles tienen una opción (`Fn` + `Esc`) para cambiar este comportamiento.

## 🇪🇸 Teclado en español
Esta guía usa los nombres de un teclado español: `Supr`, `Inicio`, `Fin`, `RePág`, `AvPág`, `ImprPant`. Algunos atajos usan símbolos que en el teclado español están en otro sitio:

- `` ` `` (acento grave): en los teclados en inglés está encima de `Tab`. En los atajos, con teclado español **suele ser la `Ñ`**: por ejemplo, la terminal de VS Code se abre con `Ctrl` + `Ñ`.
- `/`, `[`, `]` o `\`: en el teclado español están en otro sitio, así que la tecla real del atajo cambia. **Visual Studio y VS Code te muestran la combinación correcta para tu teclado** junto a cada opción de los menús (por ejemplo, *Editar > Alternar comentario de línea*). Para comentar código, `Ctrl` + `K`, `Ctrl` + `C` funciona con cualquier teclado.
- Si un atajo con símbolo no funciona, búscalo en la configuración de la app (en VS Code: `Ctrl` + `K`, `Ctrl` + `S`).

## 🟢🟡🔴 Niveles
Cada atajo tiene un nivel para que sepas por dónde empezar:

- **Básico**: imprescindibles. Apréndete estos primero.
- **Intermedio**: muy útiles cuando ya te manejas.
- **Avanzado**: para sacar el máximo partido.

> [!TIP]
> **Consejo para aprender:** elige 3 atajos básicos y úsalos durante una semana hasta que te salgan solos. Luego añade otros 3. Usa el modo **Practicar** de la web para repasar.
