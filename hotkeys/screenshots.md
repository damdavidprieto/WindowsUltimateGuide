# 📸 Capturas de Pantalla y Grabación

Haz fotos y vídeos de tu pantalla para enviar a alguien, guardar un recibo o explicar un problema.

## ✂️ Capturas
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `Shift` + `S` | Captura una zona, una ventana o toda la pantalla y la copia. | La forma más cómoda: elige la zona con el ratón y pégala (`Ctrl` + `V`) en un chat o correo. Haz clic en el aviso para dibujar sobre ella. | Básico |
| `ImprPant` | Abre la herramienta Recortes. | Igual que `Win` + `Shift` + `S`, con una sola tecla. | Básico |
| `Win` + `ImprPant` | Guarda una captura de toda la pantalla. | Cuando quieres que se guarde como archivo. Está en *Imágenes > Capturas de pantalla*. | Básico |
| `Alt` + `ImprPant` | Copia solo la ventana activa. | Para capturar una ventana sin el resto de la pantalla. | Intermedio |
| `Esc` | Cancela la captura. | Si abriste la captura sin querer. | Básico |

> [!TIP]
> Si prefieres que `ImprPant` copie toda la pantalla como antes, desactívalo en *Configuración > Accesibilidad > Teclado > Usar el botón Imprimir pantalla para abrir la captura de pantalla*.

## 🎥 Grabar la Pantalla
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `Shift` + `R` | Graba en vídeo una zona de la pantalla. | Para enseñar a alguien cómo se hace algo, o grabar un error. Se guarda en *Vídeos > Grabaciones de pantalla*. | Intermedio |
| `Win` + `G` | Abre la Xbox Game Bar. | Para grabar, ver el uso del procesador o ajustar el sonido de cada app. | Intermedio |
| `Win` + `Alt` + `R` | Empieza o detiene la grabación de la ventana activa. | Para grabar una app o un juego. Los vídeos van a *Vídeos > Capturas*. | Intermedio |
| `Win` + `Alt` + `G` | Graba los últimos instantes. | Para guardar algo que acaba de pasar en un juego (activa antes la grabación en segundo plano). | Avanzado |
| `Win` + `Alt` + `ImprPant` | Captura la ventana del juego o la app. | Para hacer una foto de un juego a pantalla completa. | Avanzado |
| `Win` + `Alt` + `T` | Muestra u oculta el temporizador de grabación. | Para ver cuánto llevas grabado. | Avanzado |
| `Win` + `Alt` + `M` | Activa o desactiva el micrófono al grabar. | Para grabar tu voz explicando lo que haces. | Avanzado |
