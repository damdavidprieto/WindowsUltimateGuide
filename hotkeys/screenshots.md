# 📸 Capturas de Pantalla y Grabación

## ✂️ Herramienta Recortes y Capturas del Sistema
| Atajo | Acción |
| :--- | :--- |
| `Win` + `Shift` + `S` | Capturar una zona, una ventana o la pantalla completa en el **portapapeles**. Haz clic en la notificación para editarla. |
| `Win` + `Shift` + `R` | **Grabar en vídeo** una zona de la pantalla. Se abre en Recortes y se guarda como MP4 en *Vídeos\Grabaciones de pantalla*. |
| `ImprPant` | Abre Recortes (opción predeterminada en Windows 11). |
| `Win` + `ImprPant` | Guardar una captura de la pantalla completa en *Imágenes\Capturas de pantalla*. |
| `Alt` + `ImprPant` | Copiar la ventana activa al portapapeles. |
| `Esc` | Cancelar la captura en curso. |

> [!TIP]
> Si prefieres que `ImprPant` copie la pantalla completa como antes, desactívalo en *Configuración > Accesibilidad > Teclado > Usar el botón Imprimir pantalla para abrir la captura de pantalla*.

## 🎮 Xbox Game Bar
Sirve para cualquier app, no solo para juegos.

| Atajo | Acción |
| :--- | :--- |
| `Win` + `G` | Abrir la Game Bar (rendimiento, audio, capturas, widgets). |
| `Win` + `Alt` + `R` | Empezar o detener la grabación de la ventana activa. |
| `Win` + `Alt` + `G` | Grabar los últimos instantes (activa antes la grabación en segundo plano). |
| `Win` + `Alt` + `ImprPant` | Captura de la ventana del juego o la app. |
| `Win` + `Alt` + `T` | Mostrar u ocultar el temporizador de grabación. |
| `Win` + `Alt` + `M` | Activar o desactivar el micrófono durante la grabación. |
| `Win` + `Alt` + `B` | Activar o desactivar HDR. |

Las capturas y vídeos de la Game Bar se guardan en *Vídeos\Capturas*.

## 🌐 Otras Capturas Útiles
| Atajo | Dónde | Acción |
| :--- | :--- | :--- |
| `Ctrl` + `Shift` + `S` | Microsoft Edge | Captura web: una zona o la **página completa**. |
| `Win` + `Shift` + `T` | PowerToys | Extractor de texto: copiar texto de cualquier parte de la pantalla (OCR). |
| `Win` + `Ctrl` + `Shift` + `M` | PowerToys | Regla de pantalla: medir píxeles. |
| `Win` + `Shift` + `C` | PowerToys | Selector de colores. |
