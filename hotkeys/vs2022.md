# 🛠️ Potenciando Visual Studio 2022

Aumenta tu productividad en el desarrollo con estos atajos, extensiones y utilidades esenciales.

## ⌨️ Atajos de Teclado (Hotkeys)

### Navegación y Búsqueda
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `,` (o `Ctrl` + `T`) | **Ir a Todo** - Busca archivos, tipos, miembros, etc. |
| `Ctrl` + `;` | Buscar en el Explorador de soluciones. |
| `Ctrl` + `F` | Buscar en el archivo actual. |
| `Ctrl` + `Shift` + `F` | Buscar en toda la solución. |
| `F12` | Ir a la definición. |
| `Ctrl` + `F12` | Ir a la implementación. |
| `Shift` + `F12` | Buscar todas las referencias. |

### Edición de Código
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `Space` | Forzar IntelliSense (autocompletado). |
| `Ctrl` + `K`, `Ctrl` + `C` | Comentar bloque seleccionado. |
| `Ctrl` + `K`, `Ctrl` + `U` | Descomentar bloque seleccionado. |
| `Ctrl` + `K`, `Ctrl` + `D` | Formatear documento. |
| `Ctrl` + `.` (o `Alt` + `Enter`) | Acciones rápidas y refactorización. |
| `Ctrl` + `R`, `Ctrl` + `R` | Cambiar nombre (Rename). |
| `Shift` + `Alt` + `Enter` | Pantalla completa. |

### Depuración (Debugging)
| Atajo | Acción |
| :--- | :--- |
| `F5` | Iniciar depuración. |
| `Ctrl` + `F5` | Iniciar sin depurar. |
| `F9` | Alternar punto de interrupción (Breakpoint). |
| `F10` | Paso a paso por procedimientos (Step Over). |
| `F11` | Paso a paso por instrucciones (Step Into). |
| `Shift` + `F11` | Paso a paso para salir (Step Out). |

## 🚀 Extensiones Imprescindibles

Para sacarle todo el partido a VS 2022, instala estas extensiones desde *Extensiones > Administrar extensiones*:

1.  **GitHub Copilot / Copilot Chat**: La IA definitiva para programar. Sugiere líneas enteras de código y resuelve dudas en tiempo real.
2.  **Roslynator**: Añade cientos de analizadores, correcciones y refactorizaciones que el VS nativo no trae.
3.  **CodeMaid**: Una herramienta de limpieza que formatea, organiza los `using` y simplifica el código con un solo botón (o al guardar).
4.  **Web Essentials 2022**: Si haces web (HTML/JS/CSS), este pack es vital. Incluye mejoras para CSS, minificación y validaciones extra.
5.  **Markdown Editor**: Permite previsualizar archivos `.md` como este mientras los editas.
6.  **Productivity Power Tools**: Un conjunto de mejoras de UI oficiales de Microsoft (pestañas verticales, guías de alineación, etc.).

## 🛠️ Utilidades y Pro-Tips

### Comparación de Archivos (Diff)
No necesitas herramientas externas. En la ventana **Comandos (Ctrl+Alt+A)**, escribe:
`Tools.DiffFiles "archivo1" "archivo2"` para comparar dos ficheros visualmente.

### Ventana de Comandos (PowerShell Integrado)
Usa `Ver > Terminal de visualización` (o `Ctrl` + ` ` `) para tener PowerShell o CMD sin salir del IDE. Perfecto para `git` o `dotnet`.

### Puntos de Interrupción Condicionales
En lugar de un simple Breakpoint (`F9`), haz clic derecho en el punto rojo -> **Condiciones**. Solo se detendrá si la variable cumple lo que tú digas. ¡Mucho más rápido que pulsar F5 mil veces!
