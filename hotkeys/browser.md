# 🌐 Navegadores (Edge, Chrome y Firefox)

Casi todos estos atajos funcionan igual en Microsoft Edge, Google Chrome, Firefox y Brave. Cuando hay diferencias, se indica.

## 🗂️ Pestañas y Ventanas
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `T` | Nueva pestaña. |
| `Ctrl` + `W` o `Ctrl` + `F4` | Cerrar la pestaña. |
| `Ctrl` + `Shift` + `T` | **Reabrir la última pestaña cerrada**. Púlsalo varias veces para recuperar más. |
| `Ctrl` + `Tab` / `Ctrl` + `Shift` + `Tab` | Ir a la pestaña siguiente o la anterior. |
| `Ctrl` + `1`…`8` | Ir a la pestaña con ese número. |
| `Ctrl` + `9` | Ir a la última pestaña. |
| `Ctrl` + `N` | Nueva ventana. |
| `Ctrl` + `Shift` + `N` | Ventana InPrivate (Edge) o de incógnito (Chrome). En Firefox: `Ctrl` + `Shift` + `P`. |
| `Ctrl` + clic en un enlace | Abrir el enlace en una pestaña nueva, en segundo plano. |
| `Ctrl` + `Shift` + clic en un enlace | Abrir el enlace en una pestaña nueva y cambiar a ella. |
| `Shift` + clic en un enlace | Abrir el enlace en una ventana nueva. |

## 🧭 Navegación
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `L`, `Alt` + `D` o `F6` | Ir a la barra de direcciones. |
| `Alt` + `←` / `Alt` + `→` | Atrás / Adelante. |
| `F5` o `Ctrl` + `R` | Recargar la página. |
| `Ctrl` + `F5` o `Ctrl` + `Shift` + `R` | Recargar sin usar la caché (carga forzada). |
| `Ctrl` + `F` | Buscar en la página. |
| `Espacio` / `Shift` + `Espacio` | Bajar o subir una pantalla. |
| `Inicio` / `Fin` | Ir al principio o al final de la página. |

## ⭐ Historial, Descargas y Favoritos
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `D` | Guardar la página en favoritos. |
| `Ctrl` + `Shift` + `B` | Mostrar u ocultar la barra de favoritos. |
| `Ctrl` + `H` | Historial. |
| `Ctrl` + `J` | Descargas. |
| `Ctrl` + `Shift` + `Supr` | Borrar los datos de navegación. |

## 🔍 Vista
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `+` / `Ctrl` + `-` / `Ctrl` + `0` | Ampliar, reducir o restablecer el zoom. |
| `F11` | Pantalla completa. |
| `Ctrl` + `P` | Imprimir o guardar como PDF. |

## 🛠️ Desarrolladores
| Atajo | Acción |
| :--- | :--- |
| `F12` o `Ctrl` + `Shift` + `I` | Herramientas de desarrollo. |
| `Ctrl` + `Shift` + `J` | Abrir la consola (en Firefox: `Ctrl` + `Shift` + `K`). |
| `Ctrl` + `Shift` + `C` | Inspeccionar un elemento. |
| `Ctrl` + `U` | Ver el código fuente. |

## 🟦 Solo en Microsoft Edge
| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `Shift` + `S` | Captura web (una zona o la página completa). |
| `Ctrl` + `Shift` + `,` | Activar o desactivar las pestañas verticales. |
| `F9` | Lector inmersivo (lectura sin distracciones). |
| `Ctrl` + `Shift` + `U` | Leer la página en voz alta. |
