# ⌨️ Atajos con la Tecla Windows

Los atajos `Win` + tecla son la forma más rápida de controlar Windows 11. Están ordenados por tema.

## 🧭 Sistema y Paneles
| Atajo | Acción |
| :--- | :--- |
| `Win` | Abrir o cerrar el menú Inicio. |
| `Win` + `I` | Abrir Configuración. |
| `Win` + `X` | Menú de vínculo rápido (clic derecho en Inicio): Terminal, discos, dispositivos… |
| `Win` + `A` | Configuración rápida (Wi-Fi, Bluetooth, volumen, brillo). |
| `Win` + `N` | Centro de notificaciones y calendario. |
| `Win` + `Shift` + `V` | Recorrer las notificaciones. |
| `Win` + `W` | Abrir Widgets. |
| `Win` + `Ctrl` + `V` | Elegir la salida de sonido en Configuración rápida. |
| `Win` + `K` | Transmitir a una pantalla inalámbrica. |
| `Win` + `P` | Modo de proyección (Duplicar, Extender, Solo segunda pantalla…). |
| `Win` + `Pausa` | Configuración > Sistema > Información. |
| `Win` + `L` | Bloquear el equipo o cambiar de cuenta. |
| `Ctrl` + `Shift` + `Esc` | Abrir el Administrador de tareas directamente. |
| `Ctrl` + `Alt` + `Supr` | Pantalla de seguridad (bloquear, cambiar usuario, cerrar sesión). |
| `Win` + `Ctrl` + `Shift` + `B` | Reiniciar el controlador gráfico o despertar una pantalla en negro. |
| `Win` + `Alt` + `B` | Activar o desactivar HDR. |
| `Win` + `Alt` + `D` | Mostrar u ocultar la fecha y la hora en el escritorio. |
| `Win` + `O` | Bloquear la orientación de la pantalla (tabletas y convertibles). |
| `Win` + `F` | Abrir el Centro de opiniones. |
| `Win` + `Ctrl` + `Q` | Abrir Asistencia rápida (soporte remoto). |
| `Win` + `Shift` + `A` | Mover el foco a una sugerencia de Windows, si aparece. |

## 🔍 Búsqueda y Apps
| Atajo | Acción |
| :--- | :--- |
| `Win` + `S` o `Win` + `Q` | Abrir la búsqueda. Con Click to Do activo, `Win` + `Q` abre Click to Do. |
| `Win` + `R` | Cuadro Ejecutar ([lista de comandos](../win-plus-r/essentials.md)). |
| `Win` + `E` | Abrir el Explorador de archivos. |
| `Win` + `Ctrl` + `F` | Buscar equipos en la red (en dominios). |
| `Win` + `C` o tecla **Copilot** | Abrir Copilot. Si no está disponible, abre la búsqueda. La tecla Copilot se configura en *Configuración > Personalización > Entrada de texto*. |

## ✍️ Escritura y Entrada
| Atajo | Acción |
| :--- | :--- |
| `Win` + `V` | Historial del portapapeles (actívalo la primera vez). |
| `Win` + `.` o `Win` + `;` | Panel de emojis, kaomoji, GIF y símbolos. |
| `Win` + `H` | Escritura por voz (dictado). |
| `Win` + `Alt` + `H` | Volver el foco al teclado mientras dictas. |
| `Win` + `Alt` + `K` | Silenciar o activar el micrófono en las apps compatibles (Teams, etc.). |
| `Win` + `Espacio` | Cambiar al siguiente idioma o distribución de teclado. |
| `Win` + `Shift` + `Espacio` | Cambiar al idioma o distribución anterior. |
| `Win` + `Ctrl` + `Espacio` | Volver a la última entrada que usaste. |

## 🤖 Funciones de IA (solo PC Copilot+)
| Atajo | Acción |
| :--- | :--- |
| `Win` + `J` | Abrir Recall. |
| `Win` + `Q` o `Win` + clic | Abrir Click to Do sobre lo que tienes en pantalla. |

> [!NOTE]
> Recall y Click to Do solo existen en los **PC Copilot+** y hay que activarlos en *Configuración > Privacidad y seguridad*.
