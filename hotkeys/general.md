# ⊞ Atajos con la Tecla Windows

La tecla `Win` (la del logo de Windows) es la llave maestra del sistema. Combinada con otras teclas abre apps, paneles y herramientas al instante, estés donde estés.

## 🧭 Sistema y Paneles
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` | Abre o cierra el menú Inicio. | Para buscar o abrir cualquier programa: pulsa `Win` y empieza a escribir su nombre. | Básico |
| `Win` + `I` | Abre Configuración. | Para cambiar el fondo, el Wi-Fi, la impresora, las actualizaciones… | Básico |
| `Win` + `X` | Abre el menú de vínculo rápido (clic derecho en Inicio). | Para llegar rápido a Terminal, Administrador de dispositivos, Discos o Apagar. | Intermedio |
| `Win` + `A` | Abre la Configuración rápida. | Para activar el Wi-Fi o Bluetooth, o cambiar el volumen y el brillo. | Básico |
| `Win` + `N` | Abre las notificaciones y el calendario. | Para revisar avisos que te has perdido o mirar el calendario. | Básico |
| `Win` + `Shift` + `V` | Recorre las notificaciones una a una. | Para responder o descartar avisos sin usar el ratón. | Avanzado |
| `Win` + `W` | Abre los Widgets. | Para ver el tiempo, noticias o tu agenda de un vistazo. | Intermedio |
| `Win` + `Ctrl` + `V` | Abre la selección de salida de sonido. | Para cambiar entre altavoces y auriculares. | Intermedio |
| `Win` + `K` | Abre Transmitir. | Para enviar la pantalla a una tele o proyector inalámbrico. | Intermedio |
| `Win` + `P` | Elige el modo de proyección. | Al conectar un segundo monitor o proyector: Duplicar, Extender… | Intermedio |
| `Win` + `Pausa` | Abre *Configuración > Sistema > Información*. | Para ver el nombre del equipo, el procesador o la memoria RAM. | Avanzado |
| `Win` + `L` | Bloquea el equipo. | Siempre que te levantes del ordenador, para que nadie lo use. | Básico |
| `Ctrl` + `Shift` + `Esc` | Abre el Administrador de tareas. | Cuando un programa se queda colgado y quieres cerrarlo. | Básico |
| `Ctrl` + `Alt` + `Supr` | Abre la pantalla de seguridad. | Para cambiar de usuario, cerrar sesión o si el equipo no responde. | Básico |
| `Alt` + `F4` (en el escritorio) | Abre el diálogo de apagado. | Para apagar o reiniciar rápido: pulsa `Win` + `D` y luego `Alt` + `F4`. | Intermedio |
| `Win` + `Ctrl` + `Shift` + `B` | Reinicia el controlador gráfico. | Cuando la pantalla se queda negra o congelada. | Avanzado |
| `Win` + `Alt` + `B` | Activa o desactiva el HDR. | Si tienes un monitor HDR y quieres cambiarlo para un juego o vídeo. | Avanzado |
| `Win` + `Alt` + `D` | Muestra u oculta la fecha y la hora en el escritorio. | Si quieres tener siempre la fecha a la vista. | Avanzado |
| `Win` + `O` | Bloquea la orientación de la pantalla. | En tabletas y convertibles, para que la pantalla no gire. | Avanzado |
| `Win` + `F` | Abre el Centro de opiniones. | Para enviar a Microsoft un problema o una sugerencia. | Avanzado |
| `Win` + `Ctrl` + `Q` | Abre Asistencia rápida. | Para que alguien de confianza te ayude conectándose a tu PC (o al revés). | Intermedio |
| `Win` + `Shift` + `A` | Lleva el foco a una sugerencia de Windows. | Cuando aparece una sugerencia y quieres verla sin el ratón. | Avanzado |

## 🔍 Búsqueda y Apps
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `S` | Abre la búsqueda de Windows. | Para encontrar apps, archivos o ajustes escribiendo su nombre. | Básico |
| `Win` + `R` | Abre el cuadro Ejecutar. | Para lanzar herramientas escribiendo su nombre (`calc`, `notepad`…). | Intermedio |
| `Win` + `E` | Abre el Explorador de archivos. | Cada vez que necesites buscar, abrir o mover un archivo. | Básico |
| `Win` + `C` | Abre Copilot. Si no está disponible, abre la búsqueda. | Para hacer una pregunta a la IA de Microsoft. | Intermedio |
| Tecla **Copilot** | Abre Copilot (o la app que elijas). | En teclados nuevos que tienen esta tecla. Se cambia en *Configuración > Personalización > Entrada de texto*. | Intermedio |
| `Win` + `Ctrl` + `F` | Busca equipos en la red. | En redes de empresa (dominios), para localizar otros PC. | Avanzado |

## ✍️ Escritura y Entrada
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `V` | Abre el historial del portapapeles. | Para pegar algo que copiaste hace rato, no solo lo último. Actívalo la primera vez. | Básico |
| `Win` + `.` | Abre el panel de emojis, GIF y símbolos. | Para poner un emoji 😀 o un símbolo (€, ©, →) en cualquier texto. | Básico |
| `Win` + `H` | Activa la escritura por voz. | Para dictar un texto en lugar de escribirlo. | Intermedio |
| `Win` + `Alt` + `H` | Vuelve al teclado mientras dictas. | Si estás dictando y quieres corregir algo a mano. | Avanzado |
| `Win` + `Alt` + `K` | Silencia o activa el micrófono. | En videollamadas (Teams y apps compatibles) para silenciarte al momento. | Intermedio |
| `Win` + `Espacio` | Cambia al siguiente idioma o distribución de teclado. | Si escribes en varios idiomas. También sirve si el teclado "escribe raro" (cambiaste de distribución sin querer). | Intermedio |
| `Win` + `Shift` + `Espacio` | Cambia al idioma o distribución anterior. | Para volver atrás al cambiar de idioma. | Avanzado |
| `Win` + `Ctrl` + `Espacio` | Vuelve a la última entrada que usaste. | Para alternar rápido entre dos idiomas. | Avanzado |

## 🤖 Funciones de IA (solo PC Copilot+)
| Atajo | Qué hace | Cuándo usarlo | Nivel |
| :--- | :--- | :--- | :--- |
| `Win` + `J` | Abre Recall. | Para encontrar algo que viste en pantalla días atrás. | Avanzado |
| `Win` + `Q` | Abre Click to Do. Sin Click to Do, abre la búsqueda. | Para actuar sobre lo que hay en pantalla: copiar texto de una imagen, resumir… | Avanzado |

> [!NOTE]
> Recall y Click to Do solo existen en los **PC Copilot+** y hay que activarlos en *Configuración > Privacidad y seguridad*.
