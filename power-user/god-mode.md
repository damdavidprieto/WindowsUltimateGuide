# 👑 God Mode (Modo Dios)

El "God Mode" es una carpeta especial que pone todos los ajustes del Panel de Control en una lista única y fácil de buscar.

## Cómo activarlo
1. Haz clic derecho en el escritorio -> **Nuevo** -> **Carpeta**.
2. Copia y pega el siguiente nombre exacto:
   `GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}`
3. El icono de la carpeta cambiará al del Panel de Control.
4. ¡Listo! Ábrela para ver más de 200 ajustes organizados.
