# 🚀 PowerToys: Superpoderes para Windows 11

Microsoft PowerToys es un conjunto de utilidades para que los usuarios avanzados ajusten y simplifiquen su experiencia en Windows.

## 1. FancyZones
Permite crear diseños de ventana complejos y arrastrar ventanas hacia ellos.
- **Configuración:** `Win` + `Shift` + `~` para abrir el editor de zonas.
- **Uso:** Mantén presionado `Shift` mientras arrastras una ventana para ver las zonas.

## 2. PowerRename
Un módulo de shell para el cambio de nombre masivo de archivos mediante búsqueda y reemplazo o expresiones regulares.
- **Uso:** Selecciona varios archivos en el Explorador -> Clic derecho -> PowerRename.

## 3. Selector de colores (Color Picker)
Permite copiar colores de cualquier aplicación que se esté ejecutando en pantalla en varios formatos (HEX, RGB, etc.).
- **Atajo:** `Win` + `Shift` + `C`.

## 4. PowerToys Run
Un lanzador rápido para usuarios avanzados que contiene funciones adicionales sin perder el rendimiento.
- **Atajo:** `Alt` + `Space` (similar a Raycast en Mac o Alfred).
