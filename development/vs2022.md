# 🛠️ Visual Studio 2022 / 2026

Atajos, extensiones y trucos para programar más rápido. **Visual Studio 2026** usa el mismo esquema de teclado que la versión 2022, así que todo lo de esta página sirve para las dos.

> [!TIP]
> Para ver o cambiar cualquier atajo: *Herramientas > Opciones > Entorno > Teclado*. Pulsa `Ctrl` + `Q` y escribe el nombre de cualquier comando para encontrarlo al instante.

## 🚀 Extensiones Recomendadas

Instálalas desde *Extensiones > Administrar extensiones*. Las extensiones de VS 2022 funcionan también en VS 2026.

1. **GitHub Copilot**: viene integrado en las versiones actuales. Completa código, responde en el chat y puede trabajar en modo agente.
2. **Roslynator**: cientos de analizadores, correcciones y refactorizaciones para C#.
3. **CodeMaid**: limpia y ordena el código (`using`, espacios, orden de miembros), también al guardar.
4. **Web Essentials 2022**: paquete de mejoras para HTML, CSS y JavaScript.
5. **Markdown Editor v2**: vista previa en directo de archivos `.md`.
6. **Productivity Power Tools 2022**: paquete oficial de Microsoft con mejoras de productividad (por ejemplo, alinear asignaciones o ajustar márgenes). Las pestañas verticales ya vienen integradas en VS sin necesidad de extensiones.

## 🛠️ Trucos Útiles

### Comparar Archivos (Diff)
No necesitas herramientas externas. Selecciona dos archivos en el Explorador de soluciones, haz clic derecho y elige **Comparar seleccionados**. También puedes abrir la ventana **Comandos** (`Ctrl` + `Alt` + `A`) y escribir:
`Tools.DiffFiles "archivo1" "archivo2"`

### Terminal Integrado
Pulsa `Ctrl` + `` ` `` (o *Ver > Terminal*) para tener PowerShell o CMD dentro del IDE. Perfecto para `git` o `dotnet`.

### Puntos de Interrupción Condicionales
En lugar de un punto de interrupción simple (`F9`), haz clic derecho en el punto rojo y elige **Condiciones**. Solo se detendrá cuando la variable cumpla la condición que pongas. ¡Mucho más rápido que pulsar `F5` mil veces!
